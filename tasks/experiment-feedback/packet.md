# 实验反馈与分层协作

目标：让实验在成功、失败、取消或需要介入时给出可决策反馈，避免主 Agent 反复轮询和阅读原始日志。用户已同意前述方案并要求实施；本轮只改善开发设施与协作，不恢复已停止的 Keep 或调用比赛模型。

分工为确定性程序采集、较低成本子 Agent 结合实验目标诊断、主 Agent 处理决策与用户汇报。远端轮询从 180 秒起步；进程退出立即收尾，不等待额外观察窗。沿用已有运行器和子 Agent 完成回传，不建立私有 App 通知服务。

验收使用已有失败证据与无模型假任务：失败也归档分析、取消区别于失败、分析错误不覆盖原结果、运行中错误提前可见、无变化不输出、终态立即返回且有稳定通知身份；验证一次活跃主会话内低成本子 Agent 的结果回传。App 关闭或主会话结束后的唤醒不在已验证能力内。

当前已完成只读调查和两个独立预演。下一步先提交任务基线，再按 [计划与协作门槛](plan.md) 实现；具体接点和预演纠正在 [设计与验收](design.md)。原 [Braid/SVC 任务](../braid-svc/packet.md) 继续停在结果复核，本任务完成不自动进入下一轮 bench。
