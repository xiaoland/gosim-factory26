# 实施与协作

本任务承接用户已讨论并同意的方案。顺序为：调查与方案讨论 → 无模型验收边界 → 独立预演 → 实现前提交 → 实现与必要检查 → 汇报，由用户决定下一轮实验。未授权比赛模型调用、bench、自动补跑或 push。

| 责任 | 所有权与输出 |
| --- | --- |
| 主 Agent | 全流程结果、错误后分析、取消语义、远程等待、项目约定与集成；不逐条阅读模型流 |
| 较低成本 worker | 独立反馈采集模块与对应测试；给出精简状态、错误去重、证据位置和等待接口 |
| 独立验收子 Agent | 无模型假任务与活跃会话完成回传，不修改产品代码 |

源码改动前提交 packet 基线。先稳定反馈模块与 lifecycle 接口，再并行实现各自文件。完成局部检查后执行一次集成验收，不因新增文档或低影响改动重复全套模型探针。

当前：预演完成，待基线提交。worker 返回必须包含改动范围、实际检查、未知与证据入口；主 Agent 独立核验。每个实验出现终态后先汇报，不自动启动补跑；程序测试不是新的模型实验。
