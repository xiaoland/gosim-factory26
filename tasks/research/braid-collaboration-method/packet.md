# research/braid-collaboration-method

- **Objective**: 形成一套可直接教给 Agent 的 Braid Issue/PR 协作方法：明确各载体权威、简洁写作与按需读取协议、thread/relationship/metadata 生命周期，并以真实案例、当前运行语义和一手研究支撑。
- **Guardrails**: 本轮是独立研究，不是旧失分根因报告续写；只读现有实现、运行证据与官方资料，只新增本目录分析文档；不修改 Braid/Factory 实现、真实 Issue/PR、Skill 或配置，不运行测试、生成、评测或模型实验。保护工作树既有大量未提交改动。
- **Verification**: 交付先回答“日常怎么用”的中文决策摘要、完整研究、实用手册与真实改写案例；关键运行语义定位到当前源码或原始记录，历史版本与当前工作树分开；外部主张链接一手来源；用静态审阅和桌面演练覆盖用户指定生命周期场景。
- **Current Truth**: 独立研究已完成。核心结论是以“当前协作接口—一次增量—一个关闭条件—按需慢层”代替全文镜像或统一字数限制。当前 I13 dirty 工作树与 I11 历史运行已分开：现源码仅 description 变化触发重建，comment/title/relationship 走增量；真实运行仍未验收。交付已覆盖真实内容墙改写、当前投影/预算/resolve/通知语义、人类标杆与 LLM/Agent 研究，且明确当前 Braid 不具备通用 labels、typed dependency 或原生 review decision。
- **Next Step**: 交由用户复核方法方向；若后续写 Skill，从 `field-guide.md` 提取最小协议并另行复核，不在本研究中修改。行为收益需另获运行授权。
