# 审计计划

2026-10-07 用户批准推进审计，要求“先规划、理解问题，找到几个关键方向、杠杆点，再分别深入开展调查、审计”。本段记录实施前审计计划；随后用户授权改造与自由提交。实际布局与验收范围见 [design.md](design.md)，实施结果见 [packet.md](packet.md)。

## 问题与预期收益

使用者需要迅速找到当前有效的操作与实现，判断证据适用于哪个版本，并在修改时知道要同步哪些消费者。已观察到的失败包括：新旧 Lab 命令在当前入口竞争、Console 的服务挂载关系被误当成产品归属、开发指南删除后仍能从取证 JSON 搜到其旧路径。用户多次修正说明，目录数量和单纯的链接检查不足以解释问题。

本轮重点验证三个可能的成因：当前答案的维护归属不够清楚；默认检索把维护材料、历史实现和证据当成同等候选；新产物持续进入错误位置，导致每次整理很快失效。每项发现须给出原始观察、影响、可区分的其它解释和具体处置，不能仅据名称或文件数量判断。

## 三个方向与关键判断

| 方向 / 负责人 | 决策问题与杠杆点 | 调查方式与停止条件 |
| --- | --- | --- |
| 当前知识导航 / 主 Agent | 应撤回哪些旧推荐、合并哪些重复答案，默认检索需排除哪些历史材料？优先修一个入口就能影响多个使用路径的位置。 | 从启动/状态/接续、模型配方、Console 归属三个真实需求走正常入口和默认检索；逐步对照源码与冻结事实。各路径至少取得一个明确成功边界或失败因果链，再定向追查共同原因。 |
| 代码与组件边界 / layout_consumers | 哪些命名、共享装配和兼容路径导致错误归属或扩大维护面？目录迁移是否接住实际责任？ | 复用已有路径调查，深入 Console 新旧入口、Lab 新旧执行与公共支持的实际导入/冻结/构建消费者。按实际边界提出保留、收拢、迁移或删除候选；停止于能支持选择，不审每行代码。 |
| 产物与运行材料 / audit_materials | 维护源码、冻结快照、报告、机器配置、缓存和运行现场应如何归位？什么生产入口导致材料重新散落？ | 使用 Git 可见清单和有界目录/记录采样，追到实际生产者及消费者；核实 reports 迁移、tasks 检索污染、experiments/local-generations/.runtime 的性质。没有实际引用及恢复边界证明的不列为可直接回收。 |

advisor 只解决跨方向的关键取舍：何种职责/检索边界足以降低反复误读，并且不妨碍找回历史、查询现有运行和维护独立组件；不作为审计 reviewer。

## 顺序与采用

1. 固定上述问题、样本选择和当前工作树身份，读取既有审计的最新结论及范围。设计文档里的目标树保持候选，不让先前目录方案预设审计答案。
2. 分别取得证据。维护源码与机器现场区分；记录读取时内容和关键行号，注明其它任务在并行修改，发现冲突再核对最新文件。所有工作产物位于本任务目录或 WorkSSD 下对应 evidence 目录。
3. 汇总可改变下一步决定的发现，按用户影响和共同原因排序。每项明确建议操作、实际范围、相关消费者、剩余未知与验证入口。没有处置依据时说明保留原因，不以历史身份无限期豁免调查。
4. 用真实导航样本回读主要结论；必要时请原 owner 补足判别事实。形成清理建议和实施顺序交用户复核，本轮不将审计结论自动应用于源码和现场。

## 证据与完成依据

调查文件分别为 audit-navigation.md、audit-code.md、audit-materials.md，综合结论归 audit.md。它们保存不同责任的结果，不重复建立全仓动态清单。

评价导航时记录实际访问路径、读取量与错误分支；计数只描述本次静态检索/人工阅读，不宣称模型 token、冷启动性能或未来耗时收益。对比检索过滤时同时核实历史仍可明确找到，避免把隐藏必要信息当作改善。

代码判断至少连到一个实际入口、依赖或制品消费者；文件相似和静态无引用不足以证明可删。产物判断连到生产者、存储身份和保留理由；不遍历整个巨大 runs 来追求表面完整，不启动或停止运行，不消耗模型或官网额度。Factory/Braid 基础设施测试仍不编写、不运行。

本轮完成时应能回答：最值得先改的三至五处是什么、为什么这些改动能同时解决多个问题、具体删/移/合/留哪些范围，以及哪些事实缺口会改变清理决定。其余问题按证据和价值明确列出，不把全仓审计等同于逐文件阅读。

## 本轮完成记录

四步均已完成。三个方向的负责人已返回并修正证据适用范围，advisor 的优先次序建议已采用；综合结果见 [audit.md](audit.md)。正常入口回读覆盖公开验收、旧运行恢复、I14 输入、模型配方与 Console；有限过滤未消除维护正文里的错误，也未覆盖普通 cells 中的历史原件。另从报告索引实际读回一份历史报告及其原始验收范围，保留了明确追溯的样本。这是审计完成时的观察；后续搜索规则、目录迁移及实际装配已完成，当前结果以 packet 为准。
