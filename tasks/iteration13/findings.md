## 因果分层与上游问题

用户指出 G01/G03/G06/G07/G02/G04 仍是表层表现，要求 I13 树记录根本问题，尚未定位的明确标注。
原账把“已证决定或根因”放在同一栏，容易将一条形成链误当成根因闭合，再从症状直接提出提示词补丁；本次纠正这一组织方式。

分析区分四层：最终结果；应用缺陷或工作浪费等表现；当时的输入、决定和操作构成的直接机制；使这种机制容易发生或持续存在的可改变上游因素。
上游因素可以是产品行为、技术机制、方法内容、材料呈现或模型判断；不预设一定是提示词缺句，也不要求所有问题收敛成一个根因。
下文“根因已定位”只针对所声明的有界机制，不声称解释全部失分或模型内部过程。
仅确认模型读到一句原则、后来仍做错，不能区分知识不足、采用入口、共享错误假设、注意力负担和能力限制。

### R01：产品语义在任务化、组合与验收中被替代［两条上游机制已定位；其它链仍待查］

G01/G06 表现为局部范围及拆分投影没有保全整体责任和适用约束；G03 表现为规定条件被更方便的实现或外部准备假设替代；G07/G02/G04 表现为已有组件、既有检查和需求编号映射被扩大解释为完整产品行为成立。
这些是“需求→任务/设计→实现/判据→完成判断”的不同失真点，不是六项已查明根因，更不能统一改名为“验收不够严格”。

现有证据已经排除若干简单解释：部分原文确实可见，部分问题已经被发现；跨任务沟通有成功样本；文件搜索的 advisor 曾采用同一种错误解释；最终检查真实通过了其自身判据。
因此“多读一次需求”“再加一个 reviewer”“再跑已有 E2E”各自都不足以闭合这些链。

**R01-a：实施边界被当成需求责任的终点，反证未进入范围裁决。** 新报告将 PR 里程碑遗漏追到初始 M5 交付已沿 Issue 对象收窄，随后 M6a 把“可能由别处负责”写成确定边界；M6b 已知 M5 只做 Issue、且已经关闭，仍以章节归属结束本项责任。
这不仅是没写 owner：已知无承接的事实没有被提出为需要改分工的矛盾。咨询输入又按局部范围筛掉这条原义务，根只对明确列为 A/B/C 的裁决请求作了有效回应。
对应 G01 的这条机制已有正反例支持：同运行 Issue8→PR17 在义务被具体保留、承接和以事实关闭时有效；无需假设通信失效或成员不会协作。
修复候选应改变范围决定与交接的返回内容，使未兑现的原义务仍可处理；不是让局部成员越界实现，也不是把所有边界声明自动变成 Braid 事件。

**R01-b：检查的执行责任交接了，证明范围的核收责任没有同样具体化。** 初始模块层负责逐场景判据；最终 PR23 的具体交付清单侧重全量执行既有 spec、干净启动、保存结果和交回候选。
接手者先把已有 mapping 当作已证前提，再用 ID 引用完整决定无需重新检查其语义充分性。因此 advisor 的“仍有关键假设”入口也未触发：当前判断已把它当作没有新假设的执行任务。
对应 G02/G04，不是缺“完整覆盖”口号，也不要求最终负责人重写全套检查；待复核方向是接手时区分“这些判据支持哪些原始主张”与“当前候选实际通过它们”，使已知排除、矛盾能重新打开前一项判断。

**修正此前的一条因果猜测：** PR23 实际读到的 SVC 明确说产品意图取自 requirements。其自行编写的 packet 将工作项排在前面，发生在放弃语义复核之后，是固化/传播该判断的因素，不是最初原因。不得据此声称 SVC 教了权威倒置，或将修改 skill 的依据顺序作为首要根治。
同样要区分两处 advisor 证据：文件搜索是输入后采用了替代解释；PR 元数据缺口则先被排除在咨询输入之外，不能归为 advisor 已审却漏判。

**R01-c / G03：规定初态被不同的替代条件接管。** 内部seed命名、较弱的cycle见证、对外部fixture的猜测及每run新数据库，分别替代了原规定对象、合取条件、应用供应义务和逐场景恢复要求。替代路径已证；最初命名决定、合取条件为何遗漏以及外部实际生命周期仍未完全确定。它们不能共用一个“测试数据不够”的根因或修复。

**R01-d / G06：早期投影遗漏与晚期未回核是两段。** 根只抽ATOMIC条目时漏掉FOLDER父层约束已证。后续PR20读到完整父文并据此纠正局部导航，排除了“后期仍拿不到原文”的解释；共享入口为何没有随之回核仍未知。需求材料应保留适用父层语境，但修补可见性不能宣称已经解决后段选择。

**R01-e / G07：新增消费者没有扩大旧更新链，既有组件证明又被外推。** Checks增加了merge快照消费者，但旧mutation只刷新checks；文件搜索则在owner/advisor已经读到目标行为后，仍借“已有blob页”确认新入口成立。前者有设计变化影响范围的具体缺口，后者是证明适用性错误，不能只让advisor再读一次相同输入。历史源码与决定链支持上述机制，本轮未重跑连续页面流程。

现有材料足以细化这些分支，不再将G03/G06/G07统一停在“继续追因”。模型为何选择替代解释、因素净贡献及修复收益仍未证；缺失的内部理由和外部生命周期不能靠重复关键词检索补出。
R02材料改写和GLM-5.3-root对照可提供后续反馈，但不替代上述区别。依据来自独立报告及其定向原件链，本轮没有重新全量审读会话。
