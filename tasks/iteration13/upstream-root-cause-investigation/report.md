### R01：原文不可见与读后外推不是一回事

- **父文投影**：root `4d03fd07`（09-29 04:25:23，原生 L12）为有效读取大文件而仅抽 `type == ATOMIC`，确实漏掉 FOLDER 的 unique Sign in。PR20 `c6aed31b`（11:32:20，L72）后续收到完整父文，`2d348c5b`（L73）用它纠正 Checks 导航。因此可见性解释只覆盖早期；不能写后期“已读懂首页冲突并故意忽略”。
- **外部准备假设**：Issue8 `58a9d136`（06:58:32，L7）已引用 isolated issues，仍称 evaluator 会用自己的 pw-* 对象；PR22/其核对者则把 scenario 恢复解释成每轮 fresh DB。局部自验正确隔离不证明应用供应义务已兑现。相反，同 run 根对 eligible 初态的明确请求真实纠正 seed，排除“根完全不管原 GIVEN”的解释。

保留现有 R 标题和已经有证据的历史状态；只细化下列子项，不直接改上层材料：

1. **R01**：保留已有两条有界机制。G06 写“早期父文漏投影；晚期可见但未回核共享入口，后者原因未定”；G03 保留内部约定/较弱见证/外部准备三类；G07 分开“新派生状态更新合同缺口”与“旧组件证明外推”。
2. **R05**：写“补录重跑与旧标签绑定、另次同名日志覆盖已证；既有方法未持续采用的原因未定”。不要把 isolated 一行也归为成功文件被覆盖。
3. **R06**：写“部分重跑由同 head 交接要求、预期审阅争议和单次成本判断驱动［有界选择理由已证；更上游净贡献未定］”。不要宣称所有重复检查均无用。
4. **R07/A01**：写“executor 已可见；部分 PR 因预期协调/合并成本与一致性风险选择自做［局部选择机制已证；收益损失未定］”。M04/M07 继续独立核实际采用，不能借 A01 一并定因。

R02 的材料缺陷和运行原因始终分开。当前修复方案的责任交接/证明范围方向有针对性；本调查不支持据此宣称新版材料必然纠正模型选择，也不支持新增强制 wrapper、强制 executor 或再加 SHA 特判。
