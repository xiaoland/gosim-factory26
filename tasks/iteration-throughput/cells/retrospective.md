下一轮保留五个可观察的动作：

1. 先用一个冻结包完成官网两题链，记录开工到首个有效官网评分和此前重包次数；其余冻结包可在本地官方测试并行运行，不把官网串行限制扩展到本地。
2. 跨组件生命周期只用实际 owner 的公开合同，记录 Braid 因 Pi 内部 child 状态误阻断的次数，目标为零。
3. 交付 commit 一形成就可独立恢复，记录“已有有效应用却重新生成”的次数，目标为零。
4. 资格检查覆盖本次变化触及的真实接缝，记录从资格通过到首个设施失败的间隔；不以检查数量代表信心。
5. controller 持有运行并收取终态，低成本 Agent 只上报语义变化；记录平台终态到本地收集的延迟及每次故障需要主 Agent 查阅原始日志的次数。
