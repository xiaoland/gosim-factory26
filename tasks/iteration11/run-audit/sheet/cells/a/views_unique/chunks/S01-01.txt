【共享契约 v1】基础 PR 与业务子 Issue 共同遵循的接口与约定。变化时在本 thread 更新并 @ 受影响负责人。
## 1. 数据模型（SQLite，全部写路径走事务）
- `workbooks(id TEXT PK, name TEXT NOT NULL, created_at, updated_at)` —— `updated_at` 是"Last updated: <值>"的唯一来源，首页与编辑器必须用同一字段同一格式化。
- `worksheets(id TEXT PK, workbook_id FK, name, position INT, row_count INT, col_count INT, last_active INT(0/1 per workbook), last_selection TEXT JSON)` —— 行列数必须显式持久（稀疏单元格不足以表达尾部插入/删除后的结构）；`last_selection` 存最近一次**成功确认**（mouseup/点击完成）的完整矩形 `{r1,c1,r2,c2,anchor:{r,c}}`，拖拽中不写库；切换工作表不得覆盖源工作表已存选择。
- `cells(worksheet_id FK, row INT, col INT, raw TEXT)` —— `raw` 为用户提交原文（公式以 `=` 开头的原文串）；不存计算结果，前端加载时重算。主键 (worksheet_id,row,col)。
- `validation_rules(id, worksheet_id FK, kind 'dropdown'|'number', range TEXT, params JSON)` —— 规则以 range 表达式存储；行列插入/删除在**同一事务**内迁移规则 range，落在被删行列上的规则一并移除。
- `filters(id, worksheet_id FK, range TEXT, column_specs JSON)` —— 筛选视图存**筛选规格**（每列的值选择/条件配置），可见性渲染时推导，不存隐藏行集合；CSV 导出与透视汇总**包含**筛选隐藏的行。
- `pivots(id, source_worksheet_id FK, source_range TEXT, config JSON(rows/col/value field + summarize), result_worksheet_id FK, last_result JSON, stale INT)` —— 三态：配置 + 最近一次成功结果快照 + 失效标记；结果工作表是普通 worksheet，内容随快照持久；被删源字段等失效场景显示错误并保留旧结果。
- 排序是**物理数据变更**（行整体移动、持久、可撤销），不是视图状态。
- SheetN/PivotN 命名从现有名字推导"第一个未用的正整数 N"，不持久计数器。
## 2. API 面（同源 `/api`，JSON；所有成功变更都更新 workbook.updated_at）
基础 PR 至少交付前 6 个，其余随对应子 Issue 交付，接口形状不变：
1. `GET /api/workbooks` → `[{id,name,updatedAt}]`
2. `POST /api/workbooks` `{name?}` → 新空白工作簿（仅 Sheet1）
3. `GET /api/workbooks/:id` → 全量快照 `{id,name,updatedAt,worksheets:[{id,name,position,isActive,rowCount,colCount,cells:[[row,col,raw]],lastSelection,validations,filters,pivots}]}`（编辑器加载入口）
4. `PATCH /api/workbooks/:id` `{name}`（trim 后非空校验在服务端同样执行）
5. `PUT /api/workbooks/:id/worksheets/:wid/cells` `{changes:[{row,col,raw}]}` —— 单元格编辑与批量粘贴共用；验证拒绝时整批 409、服务端不落任何一格
6. `PUT /api/workbooks/:id/worksheets/:wid/state` `{...worksheet 快照}` —— 撤销/重做回放用整表状态导入
7. `POST /api/workbooks/:id/worksheets`（新增）、`PATCH/DELETE /api/workbooks/:id/worksheets/:wid`（重命名/删除，含最小一表与透视源约束）
8. `POST /api/workbooks/:id/worksheets/:wid/rows|cols` `{index, count, side}` / `DELETE .../rows/:index|cols/:index` —— 结构操作：移动单元格、迁移规则 range、重写公式引用（服务端负责 cells/raw 与规则的位移；公式引用重写算法由 C 提供、两侧共用）
9. `PUT /api/workbooks/:id/worksheets/:wid/selection` `{r1,c1,r2,c2,anchor}`
10. `POST /api/workbooks/:id/worksheets/:wid/sort` `{range,sortByColumnIndex,order,hasHeader}`；filter/validation/pivot 端点随 E 交付
11. 错误格式统一：`{error:{code,message}}`；message 使用需求规定的文案（如 "Workbook name cannot be empty"、"Please enter a number from 0 to 100"）
## 3. ARIA 与可访问名称约定（验收密集区，精确实现）
- 工作表 tab：ARIA `tab` role，激活 `aria-selected="true"`；每个 tab 有按钮 "Worksheet options for <name>"（ARIA `menuitem` 菜单）。
- 网格：`role="grid"`，可访问名称 **"Worksheet grid"**，`aria-multiselectable="true"`；`gridcell` 可访问名称 = 坐标（如 `A1`）；当前单元格与选中矩形内每个 gridcell `aria-selected="true"`，矩形外每个 gridcell `aria-selected="false"`（渲染必须有界完整，不做视口虚拟化）。
- 行号 `rowheader`（可访问名称=十进制行号）、列头 `columnheader`（=列字母）；右键打开 `menuitem` 菜单。
