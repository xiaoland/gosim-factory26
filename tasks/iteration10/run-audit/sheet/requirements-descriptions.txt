18:   description: 'Supports viewing, opening, creating, renaming, importing, and exporting
19:     workbooks within the application. The home page is the entry point for workbooks;
20:     successful open, create, and import operations all enter the same editor page,
21:     and subsequent operations may modify only the currently opened workbook. After
22:     a workbook is opened, created, or imported, the editor state shown in the browser
23:     must be a stable workbook state: visiting or refreshing that
24:     exact workbook state must open the same workbook rather than another workbook or a temporary
25:     blank page, and successful workbook modifications must remain available through
26:     that visible workbook state. After returning to the home page or reopening, the workbook name, last-updated
27:     time, worksheet order, and last active worksheet remain consistent. Worksheet
28:     tabs on the same editor page use the ARIA tab role, with the active tab indicated
29:     by aria-selected="true"; the active worksheet grid uses the ARIA grid role, has
30:     the accessible name "Worksheet grid", and exposes aria-multiselectable="true".
31:     Grid cells use the ARIA gridcell role with their cell coordinates as accessible
32:     names (for example, A1); the current cell and every cell within the currently
33:     selected rectangular region expose aria-selected="true", while cells outside the
34:     region expose aria-selected="false".
