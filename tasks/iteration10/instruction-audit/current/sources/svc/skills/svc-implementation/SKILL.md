# Implementation

Use this skill when an intended change is ready to make real and its scope and useful feedback are clear enough to act.

Read [the implementation workflow](references/workflow.md) to resolve unknowns that could cause rework, make the smallest coherent change, and use local feedback to select the next step.
Use [delegation](../svc-sub-agents/SKILL.md) to decide whether and how to assign a change, and the [Executor guidance](references/delegating-implementation.md) for its implementation-specific boundary and feedback.
Return the changed artifact, actual feedback, and unresolved work.
