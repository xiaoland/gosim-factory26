# Hackathon 决赛通知原文

来源：用户于 2026-10-06 在本会话转述的组委会通知。以下保留用户提供的正文；接收日期不是主办方发布日期。官网公开日期卡片与本通知不一致时，本轮截止安排依据本通知。此文件不是新增执行授权。

---

本次Hackathon决赛赛题（竞赛界面主竞赛：Agentic Software Factory Hackathon Evolution，仅队长账号可以访问）要求选手编写智能体，在初赛产物的基础上增量完成新的需求。任务需求文档包含要改动的原始需求和本阶段新增需求；选手需要在原始功能的基础上，并通过与新增需求相关的测试用例。

基线产物与智能体执行

Hackathon-evolution竞赛提交面板提供上一阶段基线产物的下载链接，供选手在本地调试。基线产物来自本队初赛最终上榜提交：Sheet 使用该提交中 Sheet 任务最佳运行生成的产物；GitHub 如果最终采用常规赛题路线计分，则使用 GitHub 常规任务最佳运行生成的产物；如果最终采用渐进式 Stages 路线计分，则按照 Stage 3、Stage 2、Stage 1 的顺序从后向前查找，使用最后一个已有有效运行结果阶段的最佳运行产物。例如，Stage 3 已有运行结果时使用 Stage 3，否则依次回退到 Stage 2、Stage 1。

【重要须知】
1. 正式运行时，平台会在执行智能体之前自动将对应基线产物注入输出目录。因此，智能体的总体输入、输出格式应与初赛保持一致，但不得清空、重置或覆盖整个输出目录，而应在已有项目上进行增量修改。
2. 选手无需手动将下载的基线产物复制到输出目录；平台会自动完成注入，智能体理论上不需要包含任何复制、粘贴基线项目的逻辑。
3. 智能体仅读取需求，在目标输出目录上进行修改，不得尝试探测和使用未公开的测试。

提交与上榜

上榜规则与初赛一致：每支队伍取最新一次有效提交（提交时使用评测额度）上榜。有效提交是指至少有一个任务已经产生运行记录的提交。

选手可以删除提交，请注意维护提交顺序，确保希望用于最终排名的提交是当前最新的有效提交。

时间限制与截止安排

•每次容器执行最长为 24 小时，超时后平台将自动终止容器。
•决赛截止时间为 2026 年 10 月 8 日 18:00（北京时间）。
•（注意）与初赛不同，截止时平台将停止所有仍在执行的容器。此后，选手可自行决定是否删除最后一次未执行完成的提交（如有），随后排行榜定榜。

其余规则，包括排行榜计分规则等，均与初赛一致，详见初赛《参赛须知》。如对某项行为是否违规存在疑问，请及时与主办方沟通。赛事组委会保留对本次比赛规则的最终解释权与裁决权。

祝大家取得好成绩，交出亮眼的作品！
