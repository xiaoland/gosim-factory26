# 模型配置

Factory26 将供应商能力目录与本次使用的模型路由分开维护。供应商端点、请求模型 ID 和凭据变量见 [`materials/model-gateway.json`](../../materials/model-gateway.json)；角色模型和有序路由见[模型配方](../../materials/model-recipes/README.md)。配置消费与装配入口见 [Lab](../../lab/README.md)和[打包工具](../../tooling/scripts/README.md)。

凭据通过私有输入提供，不写入公开配方或可迁移应用数据。启动时冻结实际采用的配方；修改共享目录不会自动改变在途运行。明确改变接续路由时使用 Lab 的路由变更参数，并保存变更原因。

供应商套餐、模型版本、权限和价格可能变化，运行前向对应供应商核实。同名模型和稳定 alias 不证明底层版本相同；客户端 usage、估算费用和供应商账单分别记录，未知费用保留为未知。赛事费用模式由平台请求和回执确认，不能从模型端点推断。
