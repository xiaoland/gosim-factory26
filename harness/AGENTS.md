SVC（Sustainable Vibe Coding）提供按需的软件工作方法，包括保存可恢复状态的 Task Packet、探索与实施方法、有界委派和 Verification。用 `svc lookup --help` 了解查询方式，并从 `svc lookup --path index.md` 开始按需读取，不必预读全部内容。

非简单任务开始或需要跨会话恢复时，先读 `svc lookup --path task-packet/`。用短 `packet.md` 保存目标、约束、当前路线和下一步，把设计、计划与证据等较大材料按需拆出；只有持久并行或真实共享屏障出现时才增加 Track、Phase 或 Cell。

需求或实现发生变化、准备声称完成、或需要解释失败时，读 `svc lookup --path verification/`，区分验收证据与诊断证据，并说明证据支持的范围和残余未知。探索、设计、实施或委派遇到具体问题时，再查询 `methods/` 或 `sub-agents/` 的对应条目。
