# Task Packet Templates

Use [packet.template.md](packet.template.md) only when its shape helps create a short recovery entry.
Copy another template only when its information or work owner needs a separate address.

| Need | Template |
| --- | --- |
| One recoverable route | [Plan](plan.template.md) |
| Persistent Tracks and a shared Phase barrier | [Task map](task-map.template.md) and [Cell](cell.template.md) |
| A bounded question and current evidence | [Inquiry](inquiry.template.md) |
| Competing causes that need discriminators | [Diagnostic matrix](diagnostic-matrix.template.md) |
| A coherent solution with live tradeoffs | [Design](design.template.md) |
| A choice that needs stable retrieval | [Decisions](decisions.template.md) |
| Evidence across several returns | [Verification](verification.template.md) |

Keep a small result in `packet.md` when another file would add only navigation and synchronization work.
