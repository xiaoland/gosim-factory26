# Sustainable Vibe Coding

Take intended behavior from the task's requirements and use observations to understand current behavior.
Read the guidance that addresses the current question; these routes are not a sequence to complete or instructions to load every file.

| Current need | Read |
| --- | --- |
| Preserve a multi-step task across contexts or owners | [Task Packet](references/task-packet/index.md) |
| Obtain information needed for a decision | [Explore](references/methods/explore/index.md) |
| Form a coherent solution | [Design](references/methods/design/index.md) |
| Decide product behavior or develop an incomplete idea | [Product Design](references/methods/design/product.md) |
| Choose responsibilities, interfaces, or state lifetimes | [Technical Design](references/methods/design/technical.md) |
| Reconsider growing implementation complexity | [Engineering Judgment](references/methods/design/engineering-judgment.md) |
| Decide how to check that a change meets requirements | [Test Design](references/methods/design/test.md) |
| Resolve implementation risks early and execute a change | [Implementation](references/methods/implementation/index.md) |
| Interpret results and decide what remains necessary | [Verification and Validation](references/verification/index.md) |
| Reconsider repeated work that is not advancing | [Working Methods](references/methods/index.md#when-work-stops-advancing) |
| Decide whether and how to delegate | [Sub-agents](references/sub-agents/index.md) |

For an existing packet, go directly to [coordinating owners and dependencies](references/task-packet/planning.md), [information organization](references/task-packet/information.md), or [splitting an unwieldy packet](references/task-packet/growth.md) when that is the problem.
Use the [packet template](assets/templates/packet.template.md) or [template selection guide](assets/templates/index.md) only when a reusable shape helps.
For a delegation already chosen, read the [Explorer](references/sub-agents/explorer.md) or [Executor](references/sub-agents/executor.md) guidance directly.

These methods do not add product requirements or grant tool authority.
