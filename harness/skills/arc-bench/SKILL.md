# ARC Bench

处理 ARC Bench 的需求、应用设计、实现或交付时使用此技能。本次任务和输入位置来自根 Issue；从该位置读取原始材料，不以整理后的摘要替代它们。

需求包通常包含 `requirements.md`、`requirements.yaml` 和参考图片。先确认本次实际提供的文件，结合可读需求与图片理解产品要求；文件缺失、格式损坏或图片无法读取时，保留具体路径、原始错误和解释缺口，继续处理能够理解的需求，不凭预期文件名补造内容。覆盖全部需求、场景和明确指定的初始数据，保留要求的界面文字，使用可访问控件。参考图片说明视觉与交互目标，不能代替文字中的行为要求。

在选择目录、依赖和启动方式前读取 [平台交付合同](references/platform-delivery.md)，最终交付前再次据此核实候选。平台按固定目录执行安装、构建和启动；开发工具的成功结果只支持对应开发路径，不能自动证明平台路径可用。让承担相关设计、实现或验收的工作项取得本次原始需求位置和适用合同的文件入口，按需读取这些独立材料。

应用正常启动所需的初始数据属于产品交付；检查临时创建的数据和状态只服务于该次检查。交付前核实候选可从要求的初始状态正常启动，不能依赖检查已准备的数据。验收判据及证据解释沿用 `svc-verification`，此技能提供的是 ARC 平台的具体前提。
