# 实验反馈设施验收

本轮改善实验终态、错误反馈与开发协作，不调用比赛模型，不恢复已停止的 Keep 实验。此前四组接入的结果仍以 [检查点](2026-09-21-braid-svc-checkpoint.md) 为准。

## 改动与原因

原先生成失败会跳过 SVC analysis，取消会被误记成空错误的失败，生成结束也没有覆盖评测与分析的总结果。`factory.py run` 现在保存 `outcome.json`，分析收尾后发布整体终态；原始失败、评测身份和分析异常分别保留。有效评测中的失败用例不会被误记为执行失败。

原先主会话需要反复阅读状态与错误流。现在程序归并错误和重复通知，`run_feedback.py brief` 提供状态与定向证据入口；较低成本子 Agent 负责需要语义判断的筛选，主 Agent 负责决策、核验和用户汇报。WSL 与 Playground 的远端观测从 180 秒起步，进程退出不增加等待窗口。

协作门槛已写入 [AGENTS.md](../../AGENTS.md)，等待、恢复和通知边界归属 [运行文档](../../docs/deployment/evidence.md)。独立预演和实现前基线保存在提交 `e80ea0d`。

## 验收记录

`make test` 的 65 项无模型测试通过，覆盖生成失败后分析、主动中断、分析失败不覆盖原结果、预检失败、明确评测身份、三分钟观测、终态立即返回和已见事件去重。观察器自身失败也不会替换实验异常。完整测试输出留在本机 `.bootstrap/feedback-final-tests.log`；SVC status 为 healthy，文档本地链接和 diff 空白检查通过。

分别使用较低成本模型 gpt-5.6-luna 完成反馈模块实现和独立验收。验收发现 Pi 原生工具结果漏计、Codex 两种事件重复计数；该指标不能用于判断任务进展，因此直接删除。错误记录统一标为 historical，本次生命周期错误单独保留，避免将已恢复的错误误报为当前失败。

## 范围与限制

本轮没有新的 bench 分数。历史日志重放只能证明反馈能识别已有错误，不能证明比赛网关恢复。SSH 断线不表示远端已经停止；生成阶段完成不表示 bench 完成。子 Agent 通知只验证活跃主会话内的完成回传，不保证主会话结束或 App 关闭后的唤醒，也不保证跨进程恰好投递一次。
