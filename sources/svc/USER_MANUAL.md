# 使用 SVC Skills

将 `skills/` 下需要的技能目录放到 Agent 可装载的 skills 目录，保持每个目录内的相对路径。
若 Agent 支持显式指定入口，也可以直接指向对应技能的 SKILL.md。
技能没有需要安装的程序依赖。

Agent 先通过名称和描述判断适用性，读取匹配技能的入口后按当前问题选择正文。
项目文档、任务包、委派、调查、设计、实施和验收各有独立入口；项目文档覆盖产品、技术、内部设计和运行知识，任务包保存当前判断与可采用的工作材料，委派入口独立解释成果判断的方法。
文档和任务包模板均为可选材料，不要求建立固定文件集合。
不需要预读所有正文，也不需要 SVC CLI 或用户 AGENTS.md 注入。跨技能链接是按需路由；需要该方法时，将所指技能放在同一级 skills 目录，不要求为一次任务读取所有技能。
发现入口仅包含名称、description 和路径；SKILL.md 及 references 正文保留为按需读取的独立文件，不内联到 system、profile、role 或 task prompt。

Factory 的主 Agent 和内部子代理由各 variant 自行选择是否启用此技能。
SVC 不负责成员分配、模型配置或运行调度。
旧 CLI 的 lookup、analysis 等命令属于独立开发工具，不是本 skill 的使用界面。
