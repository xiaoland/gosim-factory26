# Implementation

Use this skill when an intended change is ready to make real and its scope and useful feedback are clear enough to act.

Read [planning and rehearsal](references/planning.md) to form the route, resolve consequential unknowns, and arrange dependencies, parallel work, integration, and feedback.
Read [the implementation workflow](references/workflow.md) to execute coherent changes and use the feedback to select the next step.
Use [delegation](../svc-sub-agents/SKILL.md) to decide whether and how to assign a change, and the [Executor guidance](references/delegating-implementation.md) for its implementation-specific boundary and feedback.
Use [feedback and evolution](../svc-verification/references/feedback-and-evolution.md) when choosing between exploratory feedback, test-first, and broader outcome checks.
Return the changed artifact, actual feedback, and unresolved work.
