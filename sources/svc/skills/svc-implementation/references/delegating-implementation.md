# Implementation Delegation

Use Executor for an intended change with a clear effect surface and useful local feedback.
Apply the [delegation criteria](../../svc-sub-agents/SKILL.md), then specify owned files or surfaces, constraints, permitted effects, feedback, and conditions for returning unresolved work.
An attempt or resource limit is useful when the assignment has a concrete reason for one.

Use the workflow in this skill and resolve bounded information or design gaps within the assignment.
Return the changed artifact, actual feedback, and remaining uncertainty in a form the Primary can integrate.
Repair local failures when feedback supplies a reason for the next attempt.
Return a scope, design, authority, or merge conflict that cannot be resolved within the assignment.
