# Documentation Starting Shapes

Use a template only after identifying useful content, its consumer, and its current owner.
An existing project file may already be the right place; adapt or omit sections rather than creating empty documents.
These names express responsibilities, not mandatory filenames or directories.

| Need | Optional starting shape |
| --- | --- |
| Product purpose, promises, and observable scope | [Product](product.template.md). |
| Cooperation between independent units | [Technical agreement](technical-design.template.md). |
| A repeatable operating or recovery path | [Operation](operations.template.md). |
| An admitted object or operation ambiguity | [Alignment request](alignment-request.template.md). |
| A diagnosed recurring hazard in a subtree | [Local instructions](local-instructions.template.md). |

Keep decisions and original evidence identifiable; a filled template does not establish agreement, implementation, or successful operation.
