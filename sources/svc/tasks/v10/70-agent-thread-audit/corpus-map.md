## Use in Sampling

- The pilot deliberately contrasts `SVC-A` and `OPS-B`: same broad structural
  size and coordination-metadata availability, but only the former has an
  attached task-packet layer.
- Subsequent case selection should seek maximum structural variation rather
  than cherry-picking more examples of the first pilot's mechanism: at least
  one recovery-like long case, one medium non-coordination case, and one short
  case should pressure-test the protocol.
- A coordination metadata record is a linking cue only. It does not establish
  delegation, an active sub-agent, or successful completion until the permitted
  surrounding evidence supports that interpretation.
- “No resolved attachment” means the exporter did not resolve an associated
  packet in this archive. It is not evidence that the project used no task
  packet.
