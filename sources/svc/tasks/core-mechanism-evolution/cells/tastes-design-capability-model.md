## Capability Return

- Taste is compressed consequence knowledge used as progressively loaded
  Design depth, not a global style pile or universal truth.
- Project truth, Sir's legitimate preference, rebuttable general guidance, and
  Task-local hypothesis have different authority without requiring a fixed
  metadata schema.
- Retrieve depth through Product/Technical/Test solution projections and local
  recurring design pressure. Match review carriers to the quality: visual/
  replay/Human perception, topology/change/lifecycle, or code/contracts/tests.
- Consume ECCA through semantic locality, ownership/contracts, vertical
  coherence, and explicit propagation obligations, not a branded universal
  directory/architecture.
- Rough landing adds one compact Design/taste router and reuses
  `src/sections/implementation-taste.md`; UI/UX or Architecture depth splits
  only under proven content/retrieval pressure.
- Full model: [`design/81`](../design/81-minimal-taste-design-capability-and-landing.md).
