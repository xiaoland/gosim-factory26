## Capability Return

- Sub-agent use is an economic work-placement decision; attention partition,
  trajectory shaping, and capacity scaling are evaluation dimensions.
- Primary retains Task/Human/cross-boundary authority. Assignments fit the
  Child's actual model/context/tools and use progressively loaded shared
  guidance plus Task delta/handles.
- Result route follows the consumer: Explorer returns a compressed semantic
  report without generic validator; Executor places a candidate in a bounded
  carrier for independent qualification and controlled effect.
- Only Explorer and Executor are accepted as initial preset contracts. Working
  Methods own local problem-solving logic; profiles own delegation-specific
  isolation, result/effect, and failure behavior.
- Rough landing is one compact `src/sections/sub-agents.md` plus a conditional
  Working Protocol link. No CLI, schema, directory, fixed team topology, or
  default Reviewer/QA/validator Agent is added.
- Full model: [`design/79`](../design/79-minimal-sub-agent-capability-and-landing.md).

## Relations and Return

- No hard dependency blocks inquiry, but the accepted `WP` return/authority/
  integration seam will constrain the final delegation contract.
- `VF` is a peer: it qualifies Executor candidates when appropriate but does
  not insert a validator into Explorer reports by default.
- The Cell returns a capability model to `P1`, not a runtime orchestrator,
  universal team schema, or mandatory sub-agent use.
