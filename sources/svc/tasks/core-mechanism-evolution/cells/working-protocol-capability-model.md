# Working Protocol × P1 Capability Model

- **Address**: `WP × P1`
- **Track obligation**: make selection, authority, feedback, integration,
  replanning, Human pause, and closure behavior predictable without turning
  ordinary work into a lifecycle or state-machine ceremony.
- **Phase contribution**: a reviewed capability boundary, compact operating
  model, progressive SVC landing, failure pressure, and unresolved interfaces.
- **State**: satisfied at capability-model depth; reopenable by later
  cross-Track evidence or real-task failure.

## Current Evidence State

The current canonical protocol already has useful request lenses, semantic
owner resolution, Agent Task Analysis, working postures, a Task minimum,
progressive loading, the mutation gate, and execution/verification rules. It
does not explicitly connect Plan returns, method/policy selection, autonomous
epistemic work, effect authority, feedback integration, Human pause, and the two
different closing concerns. [`V-088`](../verification.md) records that supported
gap; [`V-089`](../verification.md) is the current control-loop hypothesis.
[`V-094`](../verification.md) adds Sir's truth/stakeholder/ROI collaboration
intent, and [`V-095`](../verification.md) separates its three decision tests so
that evidence, value authority, and economic judgment do not collapse.

## Relations and Return

- Uses `TP` Plan/return/owner vocabulary but must not duplicate packet shapes.
- Must route into later `SA`, `VF`, and `TD` specialized content while keeping
  the universal protocol cheap for simple work.
- Human authority over intent, permission, material trade-offs, and acceptance
  remains distinct from the fallibility of Human factual/technical claims.
- The protocol must test epistemic support, stakeholder value, and decision
  economics separately; “ROI” includes lifecycle cost, risk, option value, and
  distributional consequence rather than acting as a single numeric oracle.
- `D-078` resolves the reopened Design-guidance proposition: local use cases
  route Product, Technical, and independent-but-claim-dependent Test Design
  projections to relevant method/taste. The next return must independently
  derive universal control guidance before asking Sir to review it.
